# Vehicle Selection Form

A full-stack TypeScript assignment built with React + Node.js.

## Features

- Cascading dropdowns for Make, Model, Badge
- Quick select preset vehicles
- Upload plain text service logbook
- Submit data to Express backend
- Displays uploaded file contents in response
- Frontend validation and loading states
- Unit tests included

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Vitest
- Testing Library

### Backend
- Node.js
- Express
- Multer
